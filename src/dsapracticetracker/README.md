# DSA Practice Tracker

A Java-based Data Structures and Algorithms practice project developed to practice and demonstrate important DSA concepts using simple, menu-driven programs.

## 📌 Project Overview

DSA Practice Tracker combines a problem-tracking system with commonly used Data Structures and Algorithms.

The project allows users to:

- Add DSA problems
- View all problems
- Search problems
- Mark problems as solved
- Filter problems by topic
- Filter problems by difficulty
- Update problems
- Delete problems
- Track solving progress
- Practice DSA algorithms directly from the main menu
